這個主題與其他三個有一個根本差異：**程式碼無法在瀏覽器裡執行**。
訓練需要 GPU，推論需要 Python 生態，兩者都不可能塞進讀者的分頁。

因此這裡的取徑是視覺化，而不是可執行的 Playground。

## 為什麼視覺化比執行更有價值

即使真的能在瀏覽器跑訓練，看著 loss 從 2.31 掉到 0.87 也學不到東西。
真正需要被看見的是形狀——梯度往哪個方向走、attention 分配到哪些 token、
高維空間投影下來的群集長什麼樣。

這些都是圖，不是數字。
